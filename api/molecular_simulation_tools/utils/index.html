molecular_simulation_tools.utils.sample_new_point(points: numpy.ndarray, minimum_distance: float, initial_spawn_distance: float | None = None, rtol: float = 1e-05, atol: float = 1e-08, n: int = 1) → numpy.ndarray[source]

Generate a new point in a random direction that is a certain distance from other points.

Parameters:

  • points (numpy.ndarray) – NxM array of coordinates of all old points, where N is the number of points and M the dimension

  • minimum_distance (float) – Minimum distance for the newly generated point to be from all other points

  • initial_spawn_distance (float | None) – Initial distance from origin. If None, is the same as minimum_distance. Default = None

  • rtol (float) – Relative tolerance. Default: 1e-5

  • atol (float) – Absolute tolerance. Default: 1e-8

  • n (int) – number of points to generate. Default: 1

Returns:

r_vec – Array of length M of coordinates of new point. Shape n*M if multiple points are being generated.

Return type:

numpy.ndarray

Raises:

ValueError – If minimum_distance or initial_spawn_distance is less or equal to 0
