.. py:function:: calculate_rmsd(atoms: ase.Atoms, target: ase.Atoms, indices: int | list[int] | None, permute: bool = True, return_permuted_target: bool = True) -> tuple[float, tuple[ase.Atoms, ase.Atoms]]

   Calculate the root-mean-squared-displacement (rmsd) between atoms `atoms` and `target`.

   :param atoms: atoms
   :type atoms: Atoms
   :param target: target
   :type target: Atoms
   :param indices: Single index, list of indices, or None if all atoms.
   :type indices: int | list[int] | None
   :param permute: Whether to permute the atom indices to get the minimum
                   rmsd. Only permutes between identical elements. Default = True.
   :type permute: bool
   :param return_permuted_target: Whether to return the permuted target,
                                  that has the minimum rmsd. Default = True.
   :type return_permuted_target: bool

   :returns: * **min_rmsd** (*float*) -- minimum rmsd
             * **return_atoms** (*tuple[Atoms, Atoms]*) -- tuple of `atoms` and `target` with only the indices in `indices`.
               If `return_permuted_target` is True, returns the permuted `target` that leads
               to the minimum rmsd.

   :raises ValueError: If the number of atoms, order of elements or cells are different between
       `atoms` and `target`.

.. py:function:: course_grain_binding_sites(sites: list[ase.Atoms], indices: int | list[int] | None, max_rmsd: int | float = 0.5, permute: bool = True, top_down: bool = False) -> list[set[int]]

   Course grain binding sites that are near to eachother.

   :param sites: List of geometries of surfaces with adsorbates.
   :type sites: list[Atoms]
   :param indices: Indices to be used to calculate the RMSD. If None, use all.
   :type indices: int | list[int] | None
   :param max_rmsd: Maximum RMSD to be considered the same site. Default = 0.5 Angstrom.
   :type max_rmsd: int | float
   :param permute: Whether to permute indices in `indices` with identical atoms. Default = True.
   :type permute: bool
   :param top_down: Only take into account the two-dimensional projected distance.
                    If True, `indices` needs to be passed as a single integer.
                    Default = False.
   :type top_down: bool

   :returns: **binding_site_sets** -- List of binding sites that are considered the same.
   :rtype: list[set[int]]

   :raises TypeError: If `top_down` is True, but `indices` is not given, or is not a single
       integer.


.. py:function:: cut_out_atoms_within_radius(atoms: ase.Atoms, center: numpy.ndarray, radius: float, keep_molecules_intact: bool = True, allowed_molecules: list[str] | set[str] | None = None, cutoffs: dict[str, float] | None = None) -> ase.Atoms

   Cut out atoms within a radius from some position.

   :param atoms: Atoms to be cut out
   :type atoms: Atoms
   :param center: Center of sphere to be cut
   :type center: numpy.ndarray
   :param radius: Radius of sphere to be cut in Angstrom.
   :type radius: float
   :param keep_molecules_intact: Identify molecules using :func:`identify_molecules`, and keep each molecule
                                 intact (i.e. if any of the atoms are inside the sphere, keep the whole molecule).
                                 Requires networkx to be installed. Default = True.
   :type keep_molecules_intact: bool
   :param allowed_molecules: List of elementary compositions of allowed molecules. If not None, check
                             that only allowed molecules are present using :func:`check_only_allowed_molecules`.
                             Default = None.
   :type allowed_molecules: list[str] | set[str] | None
   :param cutoffs: Cutoffs for each element. Dictionary with keys for the symbols and values
                   of the cutoff radii. If None, use the :data:`ase.data.covalent_radii`. Default: None
   :type cutoffs: dict[str, float] | None

   :returns: **cutout_atoms** -- Cut out atoms, with their ``pbc`` and ``cell`` attributes set to False and None.
   :rtype: Atoms

   :raises ValueError: If `radius` is more than half the minimum cell length of `atoms`.
   :raises RuntimeError: If a no atoms are found within `radius` of `center`.
   :raises RuntimeError: If a non-allowed molecule is within `radius` of `center`.

.. py:function:: find_min_height_for_adsorbate_on_surface(surface: ase.Atoms, ngrid: int | tuple[int, int], distance: float, adsorbate: ase.Atoms | None = None) -> tuple[numpy.ndarray, numpy.ndarray, numpy.ndarray]

   Find the minimum height to place an adsorbate at least `distance` away from surface atoms.

   Calculate the minimum height for `adsorbate` for it to have all its
   atoms at least `distance` away from the other atoms in `surface`.

   The returned points correspond to placing the center-of-mass of `adsorbate`
   at ``(x, y, z)``, such that the minimum distance to any atom in the surface is
   `distance`.

   :param surface: Surface
   :type surface: Atoms
   :param ngrid: Number of grid points along x and y
   :type ngrid: int | tuple[int, int]
   :param distance: Distance from all other atoms.
   :type distance: float
   :param adsorbate: Adsorbate. If None, create a dummy Atoms instance with one atom.
                     Default = None.
   :type adsorbate: Atoms | None

   :returns: * **grid_x** (*numpy.ndarray*) -- grid of positions along x
             * **grid_y** (*numpy.ndarray*) -- grid of positions along y
             * **sample_heights** (*numpy.ndarray*) -- height of the points corresponding to the points in `grid_x` and `grid_y.


.. py:function:: find_min_height_for_distance(x: float, y: float, point_coordinates: numpy.ndarray, distance: float, box_size: numpy.ndarray | None = None) -> float

   Find the minimum height for a point to be `distance` away from other points.

   Calculate the minimum height ``z`` for a point ``(x, y)`` for it to be at least
   `distance` away from all points in `point_coordinates`.

   :param x: x-coordinate of desired point
   :type x: float
   :param y: y-coordinate of desired point
   :type y: float
   :param point_coordinates: Nx2 (or more) array of N point coordinates.
   :type point_coordinates: numpy.ndarray
   :param distance: Minimum distance to all other points.
   :type distance: float
   :param box_size: Size of the box. If None, do not include periodic boundary conditions.
                    Default = None.
   :type box_size: numpy.ndarray | None

   :returns: **height** -- Minimum height required for ``(x, y)`` to be `distance` away from all other
             points.
   :rtype: float

   :raises ValueError: If no points within radius `distance` from ``(x, y)``
       are found in `point_coordinates` (in a 2D projection).
