   .. py:method:: start_from_command(command: str, directory: str | pathlib.Path = '.', force: bool = False) -> SlurmJob
      :classmethod:


      Start a slurm job from a command.

      Start a job from a command in a certain directory,
      and initialize a SlurmJob instance from the resulting job ID.

      :param command: Command to execute.
                      Should probably be something with "sbatch" and a shell script.
      :type command: str
      :param directory: Directory in which to execute command.
                        The directory should already exist. Default: "."
      :type directory: str | Path

      :returns: Initialized `SlurmJob` instance.
      :rtype: SlurmJob

      :raises ValueError: If the command does not contain a file as its second argument.
      :raises FileNotFoundError: If the executable cannot be found.
      :raises RuntimeError: If there was an error starting the job.
      :raises ValueError: If the job ID could not be extracted from the return message of starting
          the job.
