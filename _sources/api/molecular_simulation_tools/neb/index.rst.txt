.. py:function:: get_images_for_neb(initial: ase.Atoms, final: ase.Atoms, n_images: int) -> list[ase.Atoms]

   Get images to use for NEB calculations using :class:`ase.mep.neb.NEB`.

   Creates ``n_images-1`` copies of `initial`, and one copy of `final`.

   :param initial: Starting geometry
   :type initial: Atoms
   :param final: Final geometry of the NEB
   :type final: Atoms
   :param n_images: Number of images, including initial and final image
   :type n_images: int

   :returns: **images** -- List of images
   :rtype: list[Atoms]

   :raises ValueError: If `n_images` is less than 3, because that would result in no intermediate images.


.. py:function:: idpp_interpolate_subset(images: list[ase.Atoms], indices_to_idpp_interp: list[int] | numpy.ndarray, kwargs: dict[str, Any] | None = None) -> list[ase.Atoms]

   Perform IDPP interpolation for a subset of atoms in the system.

   Image dependent pair potential (IDPP, see https://pubs.aip.org/aip/jcp/article/140/21/214106/566679/Improved-initial-guess-for-minimum-energy-path)
   can generate a better initial guess for NEBs than just linear interpolation of
   the positions, but can be too expensive for large systems. This function allows you to
   only perform IDPP interpolation on the interesting region for the NEB, and just
   simple linear interpolation for the rest.

   Performs linear interpolation of all atoms first, and then takes a subset
   to perform the IDPP interpolation. The combination of the two is then
   returned.

   :param images: List of images to interpolate between the first and last.
   :type images: list[Atoms]
   :param indices_to_idpp_interp: Indices to use idpp interpolation for. The rest are interpolated linearly.
   :type indices_to_idpp_interp: list[int] | numpy.ndarray
   :param kwargs: Keyword arguments passed to :func:`ase.neb.idpp_interpolate`.
                  Default = None.
   :type kwargs: dict[str, Any] | None

   :returns: **interpolated_images** -- Interpolated images.
   :rtype: list[Atoms]

   :raises ValueError: If a key ``"mic"`` is present in `kwargs`. This is inferred from the ``pbc``
       attribute of the images.


.. py:function:: run_energy_weighted_neb(images: list[ase.Atoms], calc: ase.calculators.calculator.Calculator, fmax: float = 0.05, optimizer: type[ase.optimize.optimize.Optimizer] = LBFGS, steps: int = DEFAULT_MAX_STEPS, interpolate: Literal['linear', 'idpp'] | None = None, neb_kwargs: dict[str, Any] | None = None, optimizer_kwargs: dict[str, Any] | None = None, climb: bool = False, idpp_subset_indices: list[int] | numpy.ndarray | None = None) -> ase.mep.neb.NEB

   Do an energy-weighted climbing image nudged elastic band (EW-CI-NEB) calculation.

   See https://pubs.acs.org/doi/full/10.1021/acs.jctc.1c00462.

   :param images: List of atoms, from initial to final frame.
   :type images: list[Atoms]
   :param calc: Calculator that can calculate the potential energy and forces of the images.
   :type calc: Calculator
   :param fmax: Maximum force on the highest energy component in eV/Angstrom. Default = 0.05.
   :type fmax: float
   :param optimizer: Optimizer to use for the NEB. Default = LBFGS.
   :type optimizer: type[Optimizer]
   :param steps: Maximum number of steps. Default = :data:`ase.optimize.optimize.DEFAULT_MAX_STEPS`.
   :type steps: int
   :param interpolate: Method to interpolate see :meth:`ase.mep.neb.NEB.interpolate`.
                       If None, do not interpolate images. Default = None.
   :type interpolate: Literal['linear', 'idpp'] | None
   :param neb_kwargs: Keyword arguments passed to :class:`ase.mep.neb.NEB` upon instantiation.
                      Default = None.
   :type neb_kwargs: dict[str, Any] | None
   :param optimizer_kwargs: Keyword arguments passed to `optimizer` upon instantiation. Default = None.
   :type optimizer_kwargs: dict[str, Any] | None
   :param climb: Whether to do climbing-image (CI) NEB. This will do a two-step NEB, first just a
                 regular NEB (converged to 2*fmax), and then turn on the CI-NEB to converge to `fmax`.
                 Default = False.
   :type climb: bool
   :param idpp_subset_indices: List of indices to do idpp interpolation for with :func:`idpp_interpolate_subset`.
                               If None, and `interpolate` is ``"idpp"``, do interpolation on all atoms in the system.
                               Default = None.
   :type idpp_subset_indices: list[int] | numpy.ndarray | None

   :returns: **neb** -- Calculated minimum energy path
   :rtype: NEB

   :raises ValueError: If a key ``"climb"`` is found in `neb_kwargs`. This should be specified directly
       as a keyword argument to this function.
   :raises ValueError: If `interpolate` is not ``"idpp"``, but `idpp_subset_indices` is passed.


.. py:function:: run_neb_ts(images: list[ase.Atoms], calc: ase.calculators.calculator.Calculator, max_displacement: float = 0.01, fmax_ts: float = 0.05, replace_ts_guess: bool = True, energy_weighted_neb_kwargs: dict[str, Any] | None = None) -> tuple[list[ase.Atoms], ase.Atoms]

   Do a NEB-TS calculation.

   NEB-TS calculations consist of first doing an EW-CI-NEB calculation,
   and then a TS optimization on the climbing image.
   See https://pubs.acs.org/doi/full/10.1021/acs.jctc.1c00462

   :param images: List of images to find the minimum energy path for.
   :type images: list[Atoms]
   :param calc: Calculator that can calculate the potential energy and forces of the images.
   :type calc: Calculator
   :param max_displacement: Maximum displacement of the NEB along the minimum mode in Angstrom.
                            Default = 0.02.
   :type max_displacement: float
   :param fmax_ts: Maximum force component criterion on the transition state in eV/Angstrom.
                   Default = 0.05.
   :type fmax_ts: float
   :param replace_ts_guess: Whether to replace the TS guess of the EW-CI-NEB calculation with the
                            optimized true transition state. If False, adds it to the list
                            in the order according to the rmsd from the initial frame. Default = True.
   :type replace_ts_guess: bool
   :param energy_weighted_neb_kwargs: Keyword arguments to pass to :func:`run_energy_weighted_neb`. Default = None.
   :type energy_weighted_neb_kwargs: dict[str, Any] | None

   :returns: * **images** (*list[Atoms]*) -- Minimum energy path between the initial and final frame,
               with the transition state optimized.
             * **transition_state** (*Atoms*) -- Optimized transition state

   :raises RuntimeError: If the neb returned by :func:`run_energy_weighted_neb` does not
       contain energies.


.. py:function:: run_zoom_neb(images: list[ase.Atoms], calc: ase.calculators.calculator.Calculator, fmax: float = 0.1, fmax_zoom: float = 0.05, energy_weighted_neb_kwargs: dict[str, Any] | None = None) -> tuple[ase.mep.neb.NEB, ase.mep.neb.NEB]

   Run a ZOOM-NEB calculation.

   A ZOOM-NEB calculation consists of first doing a regular NEB calculation,
   and then a NEB calculation taking the images (in this case) one before and one
   after the TS guess to be the new endpoints.
   See https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/neb.html

   :param images: List of images to find the minimum energy path for.
   :type images: list[Atoms]
   :param calc: Calculator that can calculate the potential energy and forces of the images.
   :type calc: Calculator
   :param fmax: Maximum force component criterion on the transition state in eV/Angstrom
                to start the ZOOM. Default = 0.1.
   :type fmax: float
   :param fmax_zoom: Maximum force component criterion on the transition state in eV/Angstrom.
                     Default = 0.1.
   :type fmax_zoom: float
   :param energy_weighted_neb_kwargs: Keyword arguments to pass to :func:`run_energy_weighted_neb`. Default = None.
   :type energy_weighted_neb_kwargs: dict[str, Any] | None

   :returns: * **neb** (*NEB*) -- Calculated minimum energy path
             * **zoom_neb** (*NEB*) -- Calculated zoomed in minimum energy path
